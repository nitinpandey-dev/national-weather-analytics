# Technology Stack

## Frontend
- React
- TypeScript
- Vite / Next.js
- Tailwind CSS
- Mapbox GL JS or CesiumJS
- D3.js / Recharts

## Backend
- Python
- FastAPI
- Pydantic
- SQLAlchemy
- WebSockets

## Data
- PostgreSQL
- PostGIS
- Redis
- MinIO / S3

## Big Data
- Apache Kafka or Redpanda
- Apache Spark
- Apache Airflow

## AI/ML
- PyTorch
- scikit-learn
- Hugging Face Transformers
- Sentence Transformers
- OpenCV
- CLIP-style vision-language models

## Geospatial
- GeoPandas
- GDAL
- Rasterio
- PostGIS

## DevOps
- Docker
- Kubernetes
- GitHub Actions
- Prometheus
- Grafana

## Testing
- Pytest
- Playwright
- Jest/Vitest
- Locust or k6

## Recommended MVP
For a hackathon MVP, start with:
`React + FastAPI + PostgreSQL/PostGIS + Redis + Python ML + Docker`

Add Kafka/Spark/Airflow when the prototype is stable or when demonstrating large-scale architecture.
